# Property data and images

Dataset: **RealEstate Indian Teir1 city**, Shorty Rex, Kaggle.

- Source: https://www.kaggle.com/datasets/shortyrex/realestate-indian-teir1-city
- License shown by Kaggle: MIT
- Downloaded: 2026-09-06
- Raw file: `data/gurgaon-kaggle/RealEstate(gurgaon).csv`
- Browser download: `/gurgaon-house-listings-kaggle.csv`

The source contains 3,909 Gurgaon records scraped from 99acres. The website uses
120 deterministic sample rows, converted by `scripts/import-gurgaon.mjs`.
The source `price` values are represented in crores and are converted to INR
lakhs for the dashboard. Every record is historical test data; it is not a claim
of current price, ownership, legal status, or availability.
